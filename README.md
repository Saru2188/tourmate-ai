# TOURMATE AI

TOURMATE AI is an AI-powered travel guide and itinerary planner built using Streamlit and Ollama.

It helps users create personalized travel plans, discover local attractions, explore cultural experiences, find transportation options, and receive practical travel tips based on their destination and preferences.

## Features

- Personalized travel recommendations
- Day-wise itinerary generation
- Local food and culture suggestions
- Budget-aware trip planning
- Travel safety guidance
- Interactive AI assistant

## Tech Stack

- Python
- Streamlit
- Ollama
- Mistral
